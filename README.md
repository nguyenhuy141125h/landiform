# LANDIFORM

Website giới thiệu giải pháp LANDIFORM dành cho doanh nghiệp bất động sản.

## Chạy trên máy

Mở `index.html` trực tiếp trong trình duyệt hoặc dùng tiện ích Live Server trong VS Code.

## Các trang

- `index.html` — Trang chủ
- `solutions.html` — Giải pháp và chức năng
- `pricing.html` — Các gói và bảng so sánh
- `about.html` — Về LANDIFORM
- `contact.html` — Liên hệ

Website sử dụng HTML, CSS và JavaScript thuần. Tài nguyên giao diện nằm trong `public/`, hình ảnh và font nằm trong `assets/`.
